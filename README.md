# Zabbix — Ferramentas e Experimentos de Monitoramento

Repositório dedicado a estudos, interfaces e experimentos relacionados a monitoramento com Zabbix, visualização operacional e apoio a rotinas de infraestrutura.

## Objetivo

Centralizar projetos e provas de conceito que ajudem a transformar dados de monitoramento em informação operacional mais clara para NOC e equipes de infraestrutura.

## Stack atual

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- Lucide React
- GitHub Pages

## Execução local

```bash
npm install
npm run dev
```

Validações disponíveis:

```bash
npm run lint
npm run typecheck
npm run build
```

## Publicação

O projeto possui configuração de publicação via GitHub Pages:

```bash
npm run deploy
```

## Direção do projeto

Este repositório é usado como laboratório técnico para recursos ligados a:

- monitoramento e observabilidade;
- dashboards e visualização de dados;
- operação de NOC;
- automação de rotinas de infraestrutura;
- integração de interfaces web com dados operacionais.
